# Google Search Region Switcher (`gl`) Chrome Extension

A lightweight Chrome extension that lets you quickly reopen the current Google Search results page in a different region by applying the `&gl=` parameter.

When you click the extension icon, it opens a new tab with the same search query but targeted to your chosen country/region.

---
## Installation (Developer Mode)

1. Clone or download this repository:

   ```bash
   git clone https://github.com/yourname/google-gl-switcher.git
   ```

2. Open Chrome and go to: `chrome://extensions`

3. Enable Developer mode (top right)

4. Click Load unpacked

5. Select the folder containing this extension

The extension should now appear in your toolbar.

---

## Usage

1. Perform a Google search (must be on a /search?... results page)

2. Click the extension icon

3. A new tab opens with the same search query, but with your chosen gl= region applied

---

## Configure Default Region

1. Right-click on extension icon → option


2. Enter a region code such as: `us/jp/tw/cn`

3. Click Save
